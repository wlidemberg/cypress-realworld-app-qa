# Estratégia de Testes - Real World App

## Objetivo:
Validar funcionalidades de autenticação do sistema Real World App através de testes manuais e automatizados utilizando cypress.

## Funcionalidades
- Login
- Cadastro de Usuário

## Tipos de Teste
- Testes funcionais.
- Testes positivos.
- Testes negativos.
- Testes end-to-end.

## Ferramentas
- Cypress.
- Git.
- GitHub.
- Trello

## Critérios de Sucesso
- Usuário autenticado com sucesso.
- Mensagens de erro exibidas corretamente.
- Cadastro realizado com sucesso.
- Validação de campos obrigatórios.
